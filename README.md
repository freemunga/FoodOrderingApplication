# Online Food Ordering Application - Snacks Point

## Project Overview
This web-based front-end project allows users to browse restaurant menus, filter items by category, search food dynamically, manage a cart/wishlist, and authenticate through an admin login interface.

## Tech Stack
* **HTML5**: Semantic document layout (`<header>`, `<nav>`, `<main>`, `<aside>`, `<section>`).
* **CSS3**: Responsive flexbox and grid layouts, typography, and card designs.
* **JavaScript (ES6+)**: DOM manipulation, event listeners, array operations (`filter`, `find`, `push`, `splice`), and Fetch API.
* **Git/GitHub**: Version control and source code management.
